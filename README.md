# Nobel Prize Outcomes Analysis
This project involves analyzing a dataset of Nobel Prize winners from 1901 to the present. The goal is to identify historical patterns, trends in demographics, and significant milestones using Python and Pandas.

### Key Objectives & Analysis Tasks:

* Demographic Dominance: Identify the most frequently awarded gender and birth country.

  * Stored as: top_gender (str), top_country (str).

* US Influence Over Time: Determine which decade saw the highest ratio of US-born Nobel laureates compared to the total number of winners across all categories.

  * Stored as: max_decade_usa (int).

* Gender Diversity Trends: Identify the specific combination of decade and prize category that achieved the highest proportion of female laureates.

  * Stored as: max_female_dict (dict) — e.g., {decade: "category"}.

* Historical Milestones: Extract the name and category of the first woman to ever receive a Nobel Prize.

  * Stored as: first_woman_name (str), first_woman_category (str).

* Multiple Laureates: Identify all individuals or organizations that have been honored with the Nobel Prize more than once.

  * Stored as: repeat_list (list).
